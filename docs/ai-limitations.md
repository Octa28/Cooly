# AI limitations log

Dated, factual bullets each time AI output was wrong, inaccessible, insecure, biased, generic-looking or misread the context. Format: CLAUDE.md section 14.2.

- **2026-11-25 · Worked from a stale project guide.** Claude Code started building without running `git pull`, so it followed the old CLAUDE.md (course notes) instead of the team's new project guide. **Impact:** a whole screen was built in the wrong stack (static HTML, not Next.js) and with visuals the guide bans (emoji, gradients, blur, parallax, staggered fade-ins, an indigo accent, a big centred hero), directly on `main`, without the lo-fi step. **Fix:** the teammate noticed; the work was moved to a feature branch and a rebuild was proposed.
- **2026-11-25 · Claimed accessibility it had not measured.** The first summary said contrast passed, but control borders were 1.3–1.5:1 (needs ≥ 3:1) and the chip remove button was 32 px (needs ≥ 44 px). There was also no undo for destructive actions. **Impact:** WCAG 2.2 AA failures that were reported as passes. **Fix:** measured, then fixed after the teammate asked.
- **2026-11-25 · CSS specificity bug.** The status colours were defined before `.card`, whose neutral defaults overrode them, so green/yellow/red badges rendered grey. **Impact:** the core status signal was invisible. **Fix:** caught in the AI's own browser check; rules reordered.
- **2026-11-25 · Generic look by default.** Without the design rules, the AI reached for the usual "AI app" style: emoji everywhere, gradient image tiles, glass blur and big rounded cards with shadows. This is "convergence to the mean" from Lecture 6.
- **2026-11-25 · Didn't know the new Next.js version.** Next 16 enables "instant navigation" checks by default. The AI's usual patterns (`redirect()` in `app/page.tsx`, awaiting `params` at the top of a page) raised errors in development. **Fix:** read the docs bundled in `node_modules/next/dist/docs`, then used a config redirect and a `<Suspense>` boundary.
- **2026-11-25 · CSS cascade layers.** A global `:focus-visible` rule outside any layer overrode Tailwind utilities, so the search field showed a second focus box. **Fix:** moved it into `@layer base`.
- **2026-11-25 · Motion crept back in.** The reorder animation also faded in every card on page load, which CLAUDE.md 11.8 doesn't allow. Caught in the AI's own browser check. **Fix:** only animate after the first render.
- **2026-11-25 · Invented data.** All 19 recipes, 45 ingredients, the allergen tags and the "popular" order were written by the AI. They look plausible but nobody has checked them, and the allergen tags matter for safety. Listed in `docs/data-notes.md`.
